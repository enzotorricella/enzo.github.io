# ETorri

Portfolio personal de Enzo Torricella, orientado a desarrollo .NET, soporte de aplicaciones e integracion IT/OT.

## Comandos

```bash
npm install
npm run dev
npm run build
```

Para compilar la version del VPS en dominio raiz:

```bash
VITE_BASE=/ npm run build
```

## Estructura principal

- `src/App.jsx`: contenido y estructura de la pagina.
- `src/styles.css`: estilos visuales, responsive y animaciones.
- `src/assets/`: imagenes usadas por la version actual.
- `index.html`: metadata base de Vite.

Los proyectos antiguos del portfolio fueron movidos a una carpeta de respaldo fuera del repo para dejar visible solo la version actual.
